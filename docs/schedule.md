# Спецификация расписания

- Часовой пояс владельца: `Asia/Almaty`.
- Рабочие часы: понедельник–пятница, 09:00–18:00.
- Шаг стартов слотов: 30 минут.
- Слот длится столько, сколько выбранный тип встречи; он должен целиком помещаться в рабочие часы.
- Окно записи: 14 календарных дней, начиная со следующего дня (завтра), сдвигается с течением времени.
- Пересечения запрещены для любых типов встреч, включая частичное наложение. Встреча может начинаться в момент окончания предыдущей.
