# Спецификация расписания

- Часовой пояс владельца: `Asia/Almaty`. API отдаёт его в `GET /api/owner` (`timezone`), время в запросах и ответах — в UTC (см. [api.md](api.md#время)).
- Рабочие часы: понедельник–пятница, 09:00–18:00. Праздников и перерывов нет.
- Шаг стартов слотов: 30 минут, общий для всех типов встреч. Старты: 09:00, 09:30, …
- Слот длится столько, сколько выбранный тип встречи (15–540 минут). Длительность не обязана быть кратной шагу, но слот должен целиком помещаться в рабочий день: конец не позже 18:00. Например, для 45 минут последний старт — 17:00, для 540 минут единственный старт — 09:00.
- Окно записи: 14 календарных дней, начиная со следующего дня (завтра), то есть с завтра по завтра + 13 по `Asia/Almaty`. Окно сдвигается с течением времени. Выходные внутри окна занимают дни, но слотов не дают.
- Пересечения запрещены для любых типов встреч, включая частичное наложение. Встреча может начинаться в момент окончания предыдущей.
- Бронь принимается, только если `start` совпадает со стартом слота по этим правилам, иначе `400 SLOT_OUT_OF_RANGE`; пересечение — `409 SLOT_TAKEN`.
- Константы расписания задаются в конфигурации бэкенда и через API не меняются.
