# Интернационализация

- Языки интерфейса: русский (`ru`, основной и язык по умолчанию) и английский (`en`).
- Переключатель языка в шапке. Выбор сохраняется в `localStorage`. Если выбора нет, язык определяется по языку браузера, при неподдерживаемом используется `ru`.
- Все тексты интерфейса лежат в файлах переводов `frontend/src/locales/ru.json` и `en.json`, строки в компонентах не зашиваются. Набор ключей в обоих файлах должен совпадать (проверяется тестом).
- Даты и время форматируются по выбранной локали (`Intl`/`dayjs`) в часовом поясе владельца `Asia/Almaty`.
- Бэкенд не локализует тексты. Он возвращает коды ошибок из списка в [api.md](api.md#ошибки), а фронтенд переводит их по ключам `errors.<code>`. Названия и описания типов встреч вводит владелец, они не переводятся.
- Playwright e2e проверяют переключение языка и основной сценарий на обоих языках.
