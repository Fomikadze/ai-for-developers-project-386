# Фронтенд

Экраны описаны по скриншотам из `references/img/`. Скриншоты — визуальный ориентир, при расхождении с этим файлом прав этот файл.

## Маршруты и экраны

## Тема и layout

- Тема Mantine в `app/theme.ts`: только светлая, основной цвет `orange`, радиус `md`, карточки с рамкой и мягкой тенью. Шрифты Roboto (текст и заголовки) и Roboto Mono (моноширинный), подключаются в `main.tsx`.
- Общий layout (`components/Layout.tsx`) на всех страницах: градиентный фон (голубой слева, персиковый справа) и шапка.
- Шапка: иконка календаря и «Calendar» (ссылка на главную), ссылки «Записаться» и «Админка» с подсветкой текущего раздела, переключатель языка (см. [i18n.md](i18n.md)). Бургер-меню нет.
- Неизвестный путь и ошибка роутера показывают страницу 404 в общем layout: «Страница не найдена» и кнопка «На главную».

## Тип встречи и выбранный слот в адресе

- Отдельного запроса типа по `id` нет. `/book/:meetingTypeId` и `/book/:meetingTypeId/confirm` берут тип из `GET /api/meeting-types` (тот же запрос TanStack Query, что и каталог `/book`) и ищут его по `id`.
- Если типа с таким `id` нет, страница показывает в общем layout состояние «Тип встречи не найден» и кнопку «К выбору встречи» (`/book`).
- Выбранный слот передаётся в адресе: «Продолжить» ведёт на `/book/:meetingTypeId/confirm?start=<ISO 8601 UTC>`. Если `start` нет или он не разбирается как дата, страница перенаправляет на `/book/:meetingTypeId`. Устаревший слот фронтенд не проверяет: его отклонит сервер (`400 SLOT_OUT_OF_RANGE` или `409 SLOT_TAKEN`).
- `/book/success` показывает бронь из ответа `201`. `GET /api/bookings/{id}` нет.

## Поведение экрана выбора слота

- API возвращает только свободные слоты на всё окно записи (см. [api.md](api.md)). Занятых слотов фронтенд не знает и не показывает, в отличие от скриншота.
- Календарь показывает месяц. Фронтенд группирует слоты по дням в часовом поясе владельца. Под числом дня выводится количество свободных слотов. Дни без свободных слотов и дни вне окна записи (см. [schedule.md](schedule.md)) неактивны.
- Стрелки переключают месяц, но только в пределах окна записи.
- По клику на день справа выводятся свободные слоты этого дня. Если их нет, показывается сообщение «Нет свободного времени».
- «Продолжить» активна только после выбора слота. «Назад» возвращает на `/book`.
- Выбранные дата и время показываются в левой колонке.
- Время выводится в часовом поясе владельца.

## Структура `frontend/src/`

```text
api/generated/     # SDK из openapi.yaml, не коммитится (см. api.md)
app/               # корневой компонент, роутер, провайдеры (Mantine, Query, i18n)
pages/             # по папке на маршрут: home, book-catalog, book-slot, book-confirm, book-success, admin, not-found
components/        # переиспользуемые компоненты (layout, шапка, карточка типа, календарь, список слотов)
locales/           # ru.json, en.json (см. i18n.md)
lib/               # утилиты: форматирование дат, нормализация телефона
```

Страница не обращается к `fetch` напрямую, только через SDK и хуки запросов.

## Библиотеки

- Роутинг: React Router (`createBrowserRouter`).
- Запросы к API: TanStack Query. Плагин `@tanstack/react-query` для `@hey-api/openapi-ts` генерирует фабрики `xxxOptions` и `xxxMutation` (имена из operationId, см. [api.md](api.md#эндпоинты)), их передают в `useQuery` и `useMutation`. Готовые хуки `useXxx` не генерируются.
- Формы и валидация: `@mantine/form`. Форма гостя проверяется zod-схемами, которые генерирует плагин `zod` для `@hey-api/openapi-ts` из паттернов контракта, через `zodResolver`. Так правила имени, email и телефона совпадают с бэкендом (см. [api.md](api.md#данные-гостя)).
- Календарь: `@mantine/dates` поверх `dayjs`.
- Телефон: `libphonenumber-js` приводит ввод к E.164 (см. [api.md](api.md#телефон)).

## Работа с API

- В режиме разработки Vite проксирует `/api` на `http://localhost:8080`. SDK использует относительный базовый URL `/api`.
- Ошибка SDK — тело `{ code, message }` без HTTP-статуса, фронтенд ветвится по `code`. Текст берётся из переводов `errors.<code>` (см. [i18n.md](i18n.md)). Код без перевода показывается общим текстом `errors.UNKNOWN`: так старая сборка в браузере переживает новый код с бэкенда.
- `INVALID_NAME`, `INVALID_EMAIL` и `INVALID_PHONE` ставятся ошибкой на соответствующее поле формы (`form.setFieldError`). Остальные коды показываются уведомлением Mantine.
- Перед отправкой формы фронтенд обрезает пробелы по краям имени и приводит телефон к E.164.
- После `409 SLOT_TAKEN` показывается уведомление «Это время уже заняли, выберите другое», список слотов перезапрашивается, а пользователь возвращается к выбору времени на `/book/:meetingTypeId`. Тип встречи и введённые данные формы сохраняются.

## Тесты

- Vitest + React Testing Library: компоненты календаря и списка слотов, форма гостя, нормализация телефона, совпадение ключей переводов.
- Playwright (`frontend/e2e/`): полный сценарий записи, конфликт слотов, переключение языка.
