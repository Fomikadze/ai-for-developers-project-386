## Поведение экрана выбора слота

- API возвращает только свободные слоты на всё окно записи (см. [api.md](api.md)). Занятых слотов фронтенд не знает и не показывает, в отличие от скриншота.
- Календарь показывает месяц. Фронтенд группирует слоты по дням в часовом поясе владельца. Под числом дня выводится количество свободных слотов. Дни без свободных слотов и дни вне окна записи (см. [schedule.md](schedule.md)) неактивны.
- Стрелки переключают месяц, но только в пределах окна записи.
- По клику на день справа выводятся свободные слоты этого дня. Если их нет, показывается сообщение «Нет свободного времени».
- «Продолжить» активна только после выбора слота. «Назад» возвращает на `/book`.
- Выбранные дата и время показываются в левой колонке.
- Время выводится в часовом поясе владельца.

## Структура `frontend/src/`

```text
api/generated/     # SDK из openapi.yaml, не коммитится (см. api.md)
app/               # корневой компонент, роутер, провайдеры (Mantine, Query, i18n)
pages/             # по папке на маршрут: home, book-catalog, book-slot, book-confirm, book-success, admin
components/        # переиспользуемые компоненты (шапка, карточка типа, календарь, список слотов)
locales/           # ru.json, en.json (см. i18n.md)
lib/               # утилиты: форматирование дат, нормализация телефона
```

Страница не обращается к `fetch` напрямую, только через SDK и хуки запросов.

## Библиотеки

- Роутинг: React Router (`createBrowserRouter`).
- Запросы к API: TanStack Query, хуки генерирует плагин `@tanstack/react-query` для `@hey-api/openapi-ts`.
- Формы и валидация: `@mantine/form`.
- Календарь: `@mantine/dates` поверх `dayjs`.
- Телефон: `libphonenumber-js` приводит ввод к E.164 (см. [api.md](api.md#телефон)).

## Работа с API

- В режиме разработки Vite проксирует `/api` на `http://localhost:8080`. SDK использует относительный базовый URL `/api`.
- Ошибки API показываются уведомлением Mantine. Текст берётся из переводов по `code` (см. [i18n.md](i18n.md)).
- После `409 SLOT_TAKEN` список слотов перезапрашивается, а пользователь возвращается к выбору времени.

## Тесты

- Vitest + React Testing Library: компоненты календаря и списка слотов, форма гостя, нормализация телефона, совпадение ключей переводов.
- Playwright (`frontend/e2e/`): полный сценарий записи, конфликт слотов, переключение языка.
